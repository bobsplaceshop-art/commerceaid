## Worked on

- **Corrected a mid-session mistake.** After reading the
  008I plan document, I claimed that Sessions 1 through
  4 had not shipped. A read of `git log` and `git status`
  showed that assertion was wrong. Sessions 1 and 2 had
  shipped in seven commits:
  `78f926b`, `203d720`, `f740f69`, `a9c5d85`, `594a4f2`,
  `da0aced`, plus the plan doc at `1020b2f`. What was
  actually uncommitted was the campaign surface (part of
  Session 2 that had not been committed) and today's
  campaign preview iframe. The plan document is a map,
  not the territory.

- **Diagnosed the CSP blocker for the campaign preview
  iframe.** The iframe was returning a broken-document
  icon because the default `frame-ancestors 'none'` and
  `X-Frame-Options: DENY` headers were being applied to
  the raw preview response. Two attempts at a
  conditional override in `.htaccess` silently no-op'd:
  `SetEnvIf` with env-guarded `Header` lines, then
  `<If "%{REQUEST_URI} =~ ...">`. Both are standard
  Apache 2.4 features. Neither fired. Diagnosis was via
  the browser Network tab: the response carried the
  default CSP despite the override being present on disk
  and `AllowOverride All` being set on the vhost.

- **Fixed the CSP override with `%{THE_REQUEST}`.** The
  condition `"%{THE_REQUEST} =~ m#^GET /commerce/ca-admin/campaigns/[0-9]+/preview\?raw=1 #"`
  matches the raw request line, which is never modified by
  `mod_rewrite`. This is the only condition that reliably
  works for this purpose on the installed Apache build
  (`2.4.68 Win64`) after the internal rewrite to
  `/index.php`. Scope is `?raw=1` only: the full preview
  page keeps the default `frame-ancestors 'none'` and
  `X-Frame-Options: DENY`.

- **Fixed a second blocker: `loading="lazy"` on the
  iframe.** Chrome sends a `HEAD` request first when
  lazy-loading an iframe. The router registers only `GET`
  routes for the preview URL, so the `HEAD` returned 404
  and the browser cached the failure. Removing
  `loading="lazy"` forces a `GET` directly. One-line fix.

- **Built the campaign detail and preview surfaces.** The
  detail page (`show.php`) renders stats tiles, actions,
  and an inline preview via the sandboxed iframe. The
  full-page preview (`preview.php`) renders on the admin
  shell. The raw preview (`_preview-raw.php`) renders a
  bare email document served at `?raw=1`. The iframe
  partial (`_body-preview.php`) points at the raw URL.

- **Built the iframe autogrow.** The raw preview measures
  `document.body.scrollHeight`, coalesces
  `ResizeObserver` fires in a `requestAnimationFrame`, and
  posts the height to the parent. `campaign-preview.js`
  listens and sets the iframe height. Measuring
  `body.scrollHeight` (not `documentElement.offsetHeight`)
  is the loop-break: it does not depend on the iframe's
  own viewport, so setting the iframe height cannot
  trigger another `ResizeObserver` fire. Verified in the
  browser: height resolves to `430px` for the test
  campaign.

- **Rewrote `docs/ADMIN-GUIDE.md`.** Full rewrite of the

## Bugs found

1. **Apache conditional directives no-op after internal
   mod_rewrite.** `SetEnvIf` and `<If>` on
   `%{REQUEST_URI}` both silently failed. The default CSP
   header won. Fixed by matching on `%{THE_REQUEST}`
   instead. Two failed attempts before the fix.
   Documented as Pattern 36 in `docs/REMEMBER.md`.

2. **`loading="lazy"` triggers a HEAD request that the
   router rejects.** The iframe URL returned 404 on the
   `HEAD` and the browser cached the failure. Fixed by
   removing the attribute. Documented as Pattern 37.

3. **Plan document treated as a source of truth.** My
   claim that Sessions 1 through 4 of 008I had not
   shipped was wrong. The reads (git log, git status,
   find on app/, ls on views/) corrected it. The lesson
   is the same one that motivated the entire diagnosis
   pass this session: read the codebase, not the plan
   about the codebase.

## Decisions made

- **Four-commit close, not one.** The campaign admin
  surface, the campaign preview surfaces, the guide, and
  the session file each landed separately. Splitting
  them keeps a bisect on any one change clean.

- **The iframe is the tail of Session 2, not a
  sub-stage.** It was not in the plan. But it lives on
  the campaign detail page that Session 2 built, and
  Session 2's commits had not yet landed. Folding it in
  keeps the arc honest — the plan's Session 3 has not
  started and the plan's Session 4 has not started.

- **The manual is `ADMIN-GUIDE.md`, not a new
  `docs/manual/` directory.** One authoritative
  document, updated in place. A single file is easier
  to grep and easier to keep current than a tree of
  fragments.

- **The CSP override is scoped to `?raw=1` only.** The
  full preview page (no query string) keeps the default
  framing headers. Only the endpoint designed to be
  framed receives the exemption.

- **The raw preview measures `body.scrollHeight`, not
  `documentElement.offsetHeight`.** The former does not
  depend on the iframe's own viewport. The latter does,
  and it loops.
