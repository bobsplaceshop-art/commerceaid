## Bugs found

- **`fc8a161` claimed `composer check: 0 errors`; four PHPStan errors shipped.** Three were docblock gaps. The fourth was a real contract bug in `ConfigGroup::group()` — the declared `@return` shape forbade the pair entries the method actually returns. Fixed in `d40e5b5`.
- **Two theme variable orphans in `main-v2.css`.** `var(--ra-font-body, inherit)` and `var(--ra-t-base, 200ms)` reference tokens that were never defined anywhere. The guarded fallback rendered correctly by accident. Fixed in `9b5a6bf` by writing the concrete values.
- **Two inline `@media` blocks in `newsletter.php` and `promo-panel.php`.** Responsive contract violation. Merged into one rule in `storefront-catalog.css`. Fixed in `a9917f0`.
- **`PageDraftRepository::deleteDraftTree()` filtered children to `pending_add` only.** `pending_edit` and `pending_delete` children were left orphaned with a `parent_id` pointing at a deleted row, and `DraftPublisher` then refused to publish. Fixed in `c637fb1`; `bin/cleanup-orphan-drafts.php` repairs existing rows.
- **`config[config[headline]]` double-wrap.** `show.php` and `_config-field.php` both wrapped the field name. Every block config field silently discarded its value. Fixed in `c39922f` (prior session, referenced here for the arc).
- **`/media/{id}/...` URLs built from numeric file ids across seven files.** Images would 404 with no error. Pattern 46. Fixed across `e4d4377` and `1038be6`.
- **Bootstrap modal inheriting white background in dark mode.** Pattern 49. Fixed by using the project's `.ra-modal*` classes instead of Bootstrap's `.modal` classes.
- **Pencil dead after drag.** Settings click bound per-element on load; `rerenderSidebar()` replaced the buttons and lost the handler. Fixed in `2a361af` via document-level event delegation.
- **`?>` inside a PHP docblock closes the block.** `bin/check-media-urls.php` had this. Pattern 39.
- **Trust bar rendered twice.** Header partial and page block both drew it after the migration. Fixed in `106dd53` by removing the header partial's copy.
- **`bg_url` resolver read only `image_file_id`.** After `fc8a161` added `background_image_file_id`, the renderer silently ignored it. Fixed in `106dd53`.
- **`trust-row` block type unregistered.** The partial existed but the block was not reachable from the Add Block menu. Fixed in `106dd53`.
- **`storefront-catalog.css` product-card CSS bundled into the responsive commit `a9917f0`.** Not a bug, but a message mismatch — the commit that says "move band media queries" also contains 188 lines of product card styling. The partial half landed in `b890638`. Session file records the bundling.

## Decisions made

- **`ConfigGroup` (data) vs `_config-section.php` (HTML).** The grouping logic is a pure static method. The partial renders. `view_partial()` returns HTML, not data; a partial that returned an array failed silently. Pattern 28 family.
- **Trust bar is a page block, not a header partial.** One source. Items in the navigation menu, placement in the page builder.
- **Block modals use `.ra-modal*`, never Bootstrap `.modal`.** Pattern 49. The admin runs on `data-theme="dark"`, not `data-bs-theme="dark"`. Bootstrap's variables never resolve.
- **Storefront scripts render from one partial** (`storefront.partials._scripts`). Both `layouts/main.php` and `themes/modern/layouts/main.php` call it. Pattern 50 (two layouts, one render path). New pattern; will be documented in REMEMBER.md in a follow-up.
- **A commit message that says "verified" is a promise.** Verify the promise before the next commit. `fc8a161` said `composer check: 0 errors` and four errors shipped. The follow-up commits are named so the git log records the truth: claim, then correction.
- **`git log` is the source of truth for what shipped.** The session file links to commits; the commits carry the record. The documents (STATUS, ROADMAP, COMPLIANCE) reconcile against git in the same session that finds the drift.
