## Bugs found

Two bugs, both caught by PHPStan during the build.

1. **isset() vs array_key_exists() in
   ProductImage::fromRow().**

   The first version used `isset($row['x']) &&
   $row['x'] !== null`. PHPStan reported the second
   clause as always-true because isset() is false when
   the value is null. Fixed with
   `array_key_exists(...) && ... !== null` - the correct
   check for "column present, value possibly null".

2. **Missing enctype="multipart/form-data" on the
   category editor form.**

   Caught before any upload attempt by reading the form
   tag. Same class of bug that bit the settings form in
   008G.4a. Adding the attribute was part of the same
   patch that added the file input.

A third note that is not a bug: the patch that inserted
the category image card printed "ERROR: form anchor not
found" on the first attempt, then succeeded on the
retry. The file state was verified coherent (one
enctype, one Basic information card, image card in the
right position). No action required.

## Decisions made

- **Full scope for 008G.4a.2.** Variant-specific images
  ship in this stage. No phased rollout. The schema
  supports them today.

- **Dedicated ProductImage + ProductImageRepository.**
  Separate from ProductRepository. One concept, one
  repo. Same shape as InventoryRepository.

- **attribute_value_id column added via migration 0317.**
  Distinct from variant_id. A swatch preview (Red) is
  not the same as a variant override (Red + M).

- **The Images tab is the sixth product editor tab.**
  Placed after Basic.

- **Product image uploads happen from the product
  editor, not the media library.** Same rule as
  008G.4a.1. The media page is browse + manage.

- **Swatch selector replaces the flat <select>.** Rows
  per variant axis, mini-thumbnails, out-of-stock
  greying, hero swap on click. This is session 3's
  biggest single piece.

- **Session 1 scope was backend-only.** No admin UI
  landed. Session 2 is the Images tab and the write
  side. Session 3 is the storefront consumption and
  the swatch selector.
