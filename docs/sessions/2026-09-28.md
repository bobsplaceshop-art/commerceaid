## Bugs found

Four bugs, all in the product admin action buttons. Same
family: shared markup that worked on one caller and silently
failed on another.

1. Publish button threw null-submit on the variants page.
   _action-forms.php guard checked $mode !== 'edit';
   variants.php has no $mode. Documented as Pattern 26 in
   docs/REMEMBER.md.

2. Delete button threw "RA_DeleteProduct is not defined" on
   the variants page. _delete-modal.php include forgotten on
   the second caller. Same Pattern 26.

3. Delete button threw "Invalid or unexpected token" when a
   product name contained an apostrophe. json_encode does
   not escape single quotes; the inline onclick attribute
   closed early. Documented as Pattern 13.

4. Publish button threw null-submit on the edit page. The
   four action forms were nested inside ra-product-form. The
   browser silently discards the first inner form tag.
   Documented as Pattern 27.

Also found and fixed during the audit, not tracked as bugs
because they were cosmetic:

- Catalog and product detail pages had zero horizontal
  padding. Both were overriding .sf-container padding.
- Product detail typography rendered at desktop sizes on
  mobile.
