## New patterns worth recording in REMEMBER.md

  - **Apache on Windows fails hard on any single failed
    Listen binding.** Not a warning. `AH00451: no
    listening sockets available`. The error log is
    silent for pre-log-init failures. The only way to
    see the bind failure is `httpd.exe -f <conf>` in
    the foreground. `httpd.exe -t` only checks syntax,
    not bindability. WSL cannot write to httpd.conf
    (permission error); editing requires Notepad as
    Administrator.

  - **`git update-ref -d HEAD` does not clear the
    index.** Undoing a commit that was never pushed
    requires `git reset` (or `git reset --mixed HEAD~1`)
    to clear both the branch pointer and the staged
    entries. Only the branch pointer is removed by
    update-ref; the index keeps its entries and
    `git status` shows them as `A` (added).

  - **`git add .` on a PHP site is dangerous without
    a read of the tree first.** `.env.bak-*` files,
    `.bak` backups, scratch dumps, `dist/` build
    outputs, `tools/test-*.php` dev scripts — all
    were staged by the default `git add .` in the
    alphabet-edd project. The `.gitignore` must be
    written before the first commit and the staging
    set verified with `git add --dry-run .`.
