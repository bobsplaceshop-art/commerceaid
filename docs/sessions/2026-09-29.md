## Bugs found

1. CSRF token not available on pages with no forms.

   The catalog page has no <form>. wishlist.js read
   input[name="_csrf"], got nothing, sent an empty token,
   got 403 "Session expired". Fixed by reading the
   layout's <meta name="csrf-token"> tag. Documented as
   Pattern 29 in docs/REMEMBER.md.

2. View scope leak.

   $wishlistProductIds was injected by
   StorefrontController::render() into the outer view, but
   view_partial() does not propagate outer scope. The
   partial's `?? []` silently returned empty, so hearts
   never rendered active on page load. Fixed with a
   static-cached global helper wishlist_product_ids().
   Documented as Pattern 28 in docs/REMEMBER.md.

3. Red-heart feedback (visual polish, not a bug).

   Clicking the heart now pops (380ms scale animation) and
   fills red on the accent gold. Optimistic - the pop runs
   before the server responds.

## Decisions made

- Products only, not variants. The schema reserves a
  nullable variant_id column but no code path uses it.
  Documented in the plan.
- No snapshot fields, no quantity, no status enum. The
  wishlist is a bookmark list, not a mini-cart. Documented
  in the plan.
- View-scope fix via a global helper rather than changing
  View::renderFile or every call site. The helper pattern
  mirrors csrf_token(). Documented as Pattern 28.
- Red heart (#e63946) on gold for the active state. Red is
  the universal liked affordance.
